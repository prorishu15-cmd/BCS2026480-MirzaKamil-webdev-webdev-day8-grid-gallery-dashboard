A simple and responsive website created using **HTML5 and CSS3** as part of the Day 8 Web Development assignment.

## About the Project

## CSS Concepts Covered

### CSS Grid

1. `display: grid` — Creates a grid layout.
2. `grid-template-columns` — Defines grid columns.
3. `repeat()` — Repeats column definitions.
4. `minmax()` — Sets minimum and maximum column sizes.
5. `auto-fit` — Automatically adjusts the number of columns.
6. `grid-template-areas` — Creates named layout areas.
7. `grid-area` — Places elements in specific grid areas.

### Flexbox

1. `display: flex` — Creates a flexible layout.
2. `flex-wrap` — Allows items to wrap onto new lines.
3. `flex-grow` — Controls how items use available space.
4. `justify-content` — Aligns items horizontally.
5. `align-items` — Aligns items along the cross axis.
